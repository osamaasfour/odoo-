# operation_logistics

Odoo 16 addon for logistics shipment management — track shipments, vendor costs, client invoices, and revenue.

See [operation_logistics/README.md](operation_logistics/README.md) for full documentation.

## Quick start

```bash
python3 odoo-bin -c /etc/odoo.conf -d YOUR_DATABASE -i operation_logistics --stop-after-init
```

Then open **Operations → Shipments** in Odoo.
